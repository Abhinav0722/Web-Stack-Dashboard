Replacement for Cell 6 in report_mart (Self-Healing Merge):
Keep Cells 4 and 5 as they are, and update Cell 6 to include .whenNotMatchedBySourceDelete() so orphan rows from old month_run values are automatically cleaned up without manual DELETEs:
from delta.tables import DeltaTable

primary_key_column = "claimsummaryuid"
table = "mldev.uhcunet_gold.report_mart"

final_df = final_df.dropDuplicates([primary_key_column, "month_run", "selection_type"])
delta_table = DeltaTable.forName(spark, table)

update_condition = " OR ".join([
    f"NOT (dest.{col} <=> upd.{col})"
    for col in final_df.columns
    if col not in [primary_key_column, "month_run", "selection_type"]
])

(
    delta_table.alias("dest")
    .merge(
        final_df.alias("upd"),
        f"dest.{primary_key_column} = upd.{primary_key_column} "
        f"AND dest.month_run = upd.month_run "
        f"AND dest.selection_type = upd.selection_type"
    )
    .whenMatchedUpdate(
        condition=update_condition,
        set={col: f"upd.{col}" for col in final_df.columns}
    )
    .whenNotMatchedInsertAll()
    .whenNotMatchedBySourceDelete()  # Automatically purges any stale/re-labeled month_run rows
    .execute()
)

(Note: Using Spark's null-safe equality operator NOT (dest.col <=> upd.col) replaces the verbose dest.col <> upd.col OR (dest.col IS NULL AND ...) expression while remaining 100% semantically identical.)
